🧮 Scientific Calculator

A responsive Scientific Calculator built using HTML, CSS, and JavaScript.
It provides basic arithmetic operations along with scientific functions such as trigonometric calculations, logarithms, powers, square roots, and more.

💻 How to Run
1. Clone the repository
git clone https://github.com/AshutoshKumar664/scientific-calculator.git
2. Open the project

Navigate into the project directory:

cd scientific-calculator
3. Run the calculator

Open index.html in your web browser.

You can also open the project directly in VS Code and use the Live Server extension for a better development experience.

🎯 Scientific Operations

The calculator supports several scientific operations, including:

Category	Operations
Arithmetic	+, -, ×, ÷, %
Trigonometry	sin, cos, tan
Logarithms	ln, log
Power	xʸ, ^
Root	√
Constants	π, e
Other	abs
Angle Mode	Degree / Radian
🧠 Calculator Controls
Button	Purpose
C	Clear expression
DEL	Delete the last input
Ans	Use the previous answer
M+	Add value to memory
M−	Subtract value from memory
MR	Recall memory
MC	Clear memory
History	View previous calculations
Copy	Copy the result
